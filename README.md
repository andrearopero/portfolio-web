## Tecnología

- **React 19 + TypeScript + Vite**
- Diseño claro/oscuro con acento Esmeralda Andina (`#0E7C7B`)
- Optimizada para móvil (desde 320 px) y accesible (WCAG AA, `prefers-reduced-motion`)
- Despliegue automático en GitHub Pages (workflow `.github/workflows/deploy-pages.yml`)

## Desarrollo local

```bash
git clone https://github.com/andrearopero/portfolio-web.git
cd portfolio-web
npm install
npm run dev -- --host    # o simplemente: ./run.sh
```
